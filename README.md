## What it does

`main.ts` writes one original roast line to `/output/entry.txt`:

> My phone won't unlock with my face before coffee; apparently I'm not myself until I've had caffeine.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22.18 or later. The program creates `/output` if needed, writes the line, and exits 0.
